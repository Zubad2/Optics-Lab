# Project Optics Lab

An interactive, web-based optics laboratory simulation. Explore the world of light, lenses, mirrors and rays in a digital environment.

**Explore:** [Click here!]((https://zubad2.github.io/Optics-Lab/))


## About
This project is an independent classroom style recreation inspired by educational physics simulations. 

* **Concept & Inspiration:** [PhET Interactive Simulations](https://phet.colorado.edu/), University of Colorado Boulder.
* **Purpose:** Built for educational exploration, interactive physics demonstrations and web based learning.

  
## Getting Started Locally
To run or modify this project locally, clone the repository or download whole code base as ZIP.
